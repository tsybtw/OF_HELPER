1. Перейдите в папку update, которая находится в коренной папке.

2. Для обновления самих файлов обновления переименуйте текущие файлы обновления, например в upd1 (или upd1.exe).

3. Для обновления:

  - на macOS:

    1. Кликните правой кнопкой мыши по папке update → Открыть в Терминале.

    2. Введите команду: ./upd (./upd1)

  - на Windows: 

    1. Дважды кликните по upd.exe (upd1.exe).

После обновления файлов обновления можно удалить старые файлы (upd1 или upd1.exe).
Последняя версия всегда доступна по ссылке: https://github.com/tsybtw/OF_HELPER/archive/refs/heads/main.zip
После скачивания последней версии по ссылке делать обновление через файл обновления уже не нужно.
