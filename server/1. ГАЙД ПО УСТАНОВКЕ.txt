1. Установите:
на macOS: Python, Node.js
на Windows: Python, Node.js, Java, Lightshot/ShareX, Windows Terminal

2. Перейдите по ссылке:
https://github.com/tsybtw/OF_HELPER/releases

Для macOS:
Скачайте файлы ffmpeg и ffprobe.

Для Windows: 
Скачайте файлы ffmpeg.exe и ffprobe.exe.

3. Поместите 2 скачанных файла в папку server -> crop -> ffmpeg.

4. Перейдите в папку server, разархивируйте нужный zip архив в эту же папку так, чтобы в папке server был файл main.exe (main-intel/main-arm для macOS).

Для macOS:
Нажмите правой кнопкой мыши на папку crop -> Новый терминал по адресу папки

Для Windows: 
Перейдите в папку crop и нажмите на строку пути -> Введите cmd и нажмите Enter

5. Выполните команду:
node install.js

6. Перейдите на сайт:

https://my.telegram.org/auth

    1. Введите номер телефона, к которому привязан ваш Telegram, и подтвердите вход через код из приложения.
    2. После входа выберите раздел API Development Tools.
    3. Нажмите Create New Application.

    Заполните поля:
    App title - любое название на латинице (от 5 символов).
    Short name - аналогично.
    Остальные поля можно оставить как есть.

    4. Нажмите Create application.

    5. Заполните файл .env:

    Файл может быть скрыт. Находясь в папке crop:
    На Windows: в настройках проводника включите показ скрытых файлов.
    на macOS: нажмите комбинацию Shift + Command + точка.

    API_ID=API ID (на сайте)
    API_HASH=API Hash (на сайте)
    PHONE=номер_телефона_от_аккаунта 
    FOLDER=/путь/к/папке/со/скриншотами 
 
    для копирования этого пути перейдите в свойства папки скриншотов, кликнув на нее правой кнопкой мышки и выбрав соотвествующий пункт, после чего скопируйте маршрут, вставьте его в файл и допишите /название_папки

7. Если вы пользуетесь браузером ADS, то в настройках каждого профиля:
	
    1. Перейдите в меню "отпечаток" в верхней панели
    2. Пролистайте чуть ниже, нажмите кнопку "показать больше". 
    3. Найдите пункт "Защита от сканирования портов" и поставьте его на "выключено".

8. Откройте анкеты, перейдите в расширения на каждом браузере, включите режим разработчика, обновите страничку и перетащите всю папку OF_HELPER (либо через кнопку "Загрузить распакованное расширение")
