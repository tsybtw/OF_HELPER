Убедитесь, что все шаги, описанные в файле "1. ГАЙД ПО УСТАНОВКЕ" выполнены

Запуск на macOS:
    
    1. Нажмите правой кнопкой мыши по папке server -> Новый терминал по адресу папки
    2. Выполните команду:

    ./main-arm 
    или 
    ./main-intel 
    
    в зависимости от архитектуры своего процессора

Для первого запуска на Windows:

    1. Запустите файл wt.exe в Windows Terminal.
    2. Нажмите на значок ⏷
    3. Выберите Settings (Параметры).
    4. В меню слева выберите Defaults (По умолчанию).
    5. Найдите Starting directory (Запуск каталога):
        - Уберите галочку "Use parent process directory" (Использовать каталог родительского процесса).
        - Укажите путь к папке server.
    6. Нажмите Save (Сохранить).
    7. Нажмите + (новая вкладка).
    8. Введите команду: ./main

Для следующих запусков на Windows:

    Выполняйте только пункты 1 и 8 из инструкции выше.

Для добавления расширения в браузер:

1. Включите режим разработчика на страничке chrome://extensions/
2. Обновите страничку.
3. Перетащите всю папку OF_HELPER на свободное пространство. 
4. В каждом браузере в появившемся всплывающем окне поочередно нажмите на разные ползунки.
5. Закройте всплывающее окно.

Запуск нескольких копий программы на одном компьютере (под разными ключами):

1. Для каждой копии сделайте отдельную папку OF_HELPER с разными аккаунтами, добавленными в .env файл.

2. Расширение: в браузеры закидывайте папку той копии, к которой они должны относиться.

3. Скриншоты: в scr8 сделайте отдельный bind для каждой копии (см. "2. ГАЙД ПО СКРИНШОТАМ"):
   своя папка — в FOLDER в файле .env этой копии, своя комбинация — в keybind.txt этой копии.

4. Каждая копия запускается своим main.exe (main-arm/main-intel) из своей папки server.
